# Festival de France - Gestion des Concerts et Artistes

Ce projet est un logiciel développé en .NET permettant de gérer les festivals de musique en France, en répertoriant les concerts, les artistes et leurs informations associées. Le logiciel permet aux utilisateurs de consulter les festivals à venir, de découvrir les artistes participants et d'avoir des informations détaillées sur chaque événement.

## Fonctionnalités

* **Gestion des festivals :** Affichage des festivals à venir en France.
* **Liste des concerts :** Consultation des concerts programmés lors des différents festivals.
* **Informations sur les artistes :** Détails sur les artistes participant aux festivals (biographie, genre, discographie, etc.).
* **Recherche rapide :** Recherche de concerts et d'artistes par nom, date ou région.
* **Interface intuitive :** Interface utilisateur simple et conviviale pour une navigation fluide.

## Technologies utilisées

* .NET
* WPF (Windows Presentation Foundation) pour l'interface utilisateur
* Base de données locale pour stocker les informations sur les festivals, concerts et artistes

## Installation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/AzmogEx/WPF-PROJET-CONCERT.NET.git
   ```

2. Ouvrir le projet avec Visual Studio
3. Restaurer les packages NuGet
4. Lancer l'application depuis Visual Studio

## Utilisation

1. Ouvrir le logiciel et naviguer entre les différents festivals à venir
2. Consulter la liste des concerts pour chaque festival
3. Rechercher des concerts ou des artistes spécifiques
4. Découvrir des informations détaillées sur chaque artiste et leur programmation
